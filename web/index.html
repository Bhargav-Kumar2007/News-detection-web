How It Works

Understanding the optical extraction, sequence modeling, and computer vision architectures.

⌗

1. RapidOCR Text Extraction

RapidOCR runs locally via ONNX Runtime without cloud APIs. It performs DBNet text box detection to locate text in the image, followed by CRNN text recognition to transcribe characters. The extracted string is returned directly to the backend.

RGB Pixels → DBNet Boxes → CRNN → OCR Text
T

2. BiLSTM Text Classifier

The headline and OCR text are joined with a space. The tokenizer applies lowercasing, URL replacement, and vocabulary mapping (16,449 words). A 200-dim learned embedding table feeds a Bidirectional LSTM (128 units/dir = 256 total), followed by a dense layer and sigmoid output.

Headline + OCR → Embedding (200d) → BiLSTM (256d) → Sigmoid
▧

3. ResNet-18 Image Classifier

The uploaded image is resized and center-cropped to 224×224 RGB, then normalized with ImageNet mean/std. An ImageNet-pretrained ResNet-18 extracts deep convolutional feature maps through residual skip connections, outputting 2-class softmax probabilities.

224×224 RGB → 4 Residual Stages → AvgPool → Softmax

Verified architectures, datasets, evaluation metrics, and failure modes from the training repositories.

Text Classifier (BiLSTM)

NEWS-detection-using-text / outputs/bilstm_50k_20ep
ArchitectureEmbedding (200d) + BiLSTM (128/dir) + Dropout (0.4) + FC (128) + Sigmoid
Parameters3,693,513 trainable parameters
DatasetFakeddit 2-way title dataset (clean_title, 2_way_label)
Training Splits50,000 train / 5,000 validation / 5,000 test (20 epochs)
Best Epoch MetricsVal Accuracy: 81.44% | F1: 79.57% | ROC-AUC: 89.63%
Label MappingLabel 0 = FAKE  |  Label 1 = REAL
Limitations & Blind Spots Vocabulary bounded to 16,449 words. Rare geographical proper nouns (e.g. landmarks like "Taj Mahal", local municipalities) are out-of-vocabulary and mapped to <unk>. The model classifies based on surrounding syntax and tone rather than real-world factual status.

Image Classifier (ResNet-18)

NEWS-detection-using-image / outputs/recovery/subset_resnet18
ArchitectureImageNet Pretrained ResNet-18 (4 Residual Stages + Adaptive AvgPool + FC)
Parameters~11.18 Million parameters
DatasetReCOVery News Dataset (reliable vs. unreliable news images)
Training Splits1,157 train / 137 validation / 142 test (20 epochs)
Test Set MetricsTest Accuracy: 90.14% | Fake Precision: 100% | Fake Recall: 26.32% | ROC-AUC: 76.17%
Label MappingLabel 0 = FAKE  |  Label 1 = REAL
Limitations & Blind Spots Severe class imbalance in training data (~90% real news photos). In held-out testing, 14 of 19 fake news images (73.7%) were misclassified as REAL. High-quality photographic scenes (natural lighting, landmark architecture) trigger authentic news filters, producing high-confidence false negatives on realistic fabricated photos.
⚠️
Neural Network Interpretability Notice for Examiners:

Neural networks evaluate statistical patterns learned from their training datasets. Model confidence scores reflect internal activation certainty within the feature space, not real-time factual truth. Because neither model possesses an external knowledge graph, realistic fabricated news (e.g., landmark flooding) can produce high-confidence "Real" predictions when linguistic tone and photographic textures mimic authentic reporting.
